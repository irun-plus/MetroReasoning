# 原代码到V1物理环境迁移映射

映射依据：用户上传的`MetroReasoning(4).zip`内`MetroReasoning/Env/ALNSEnv.py`、`configure.py`、`scenario.py`、`Constant.py`、`ALNS.py`及`run_alns.py`。

| 原文件/函数 | 原职责 | V1去向 | 迁移方式/说明 |
|---|---|---|---|
| `Env/Constant.py`常量 | 站点、站台、容量、运行时分、折返候选 | `Env/Constant.py` | 保留原参数主干；新增显式资源ID；对来源不明数值标注待核 |
| `Env/configure.py::Config` | 中断、搜索参数、权重、折返假设 | `Env/configure.py::Config` | 收窄为物理配置；移除ALNS搜索预算和目标权重 |
| `Env/configure.py::Config.public` | 向求解器公开配置 | `Env/Env.py::observe` | 改为结构化Snapshot；不公开真实恢复时刻 |
| `Env/scenario.py::sample_scenario` | 随机中断抽样 | `Env/configure.py::sample_disruption` | 合并scenario职责；先抽区间再抽可行时刻；无可行时刻明确报错，不重抽区间 |
| `ALNSEnv.py::ALNSEnv.__init__` | 加载时刻表/OD、初始化状态 | `Env/Env.py::Env.__init__`、`_validate_data`、`_reset_state` | 重写为物理环境初始化 |
| `ALNSEnv.py::reset` | 推演到中断时刻 | `Env/Env.py::reset`、`_advance_until` | 保留目标，改用事件队列 |
| `ALNSEnv.py::observe` | 生成决策快照和客流预测 | `Env/Env.py::observe` | 保留预测思路；快照结构不含actual字段并设为只读副本 |
| `ALNSEnv.py::initial_plan`、`safe_initial_plan` | 生成优化算法初始方案 | 暂不迁移 | 属于ALNS/规则策略，不属于物理状态转移 |
| `ALNSEnv.py::_apply_plan` | 同时处理列车动作、折返、客流限流 | `Env/Env.py::_validate_and_apply` + `TrainOperator.py` + `PassengerOperator.py` | 拆分动作类型；先全量校验，再执行，避免部分应用 |
| `ALNSEnv.py::_append_reverse_train` | 追加反向列车记录 | `Env/Env.py::_process_turnback_complete` | 不再增加车底/列车对象；同一train_id和vehicle_id更新方向与后续任务 |
| `ALNSEnv.py::_validate_schedule` | 运行图可行性校验 | `Env/Env.py::_process_departure`及事件约束 | V1在发车事件校验封锁和追踪间隔；未实现全联锁运行图优化 |
| `ALNSEnv.py::evaluate` | 复制状态试算候选并算分 | 暂不迁移 | 候选评价和目标函数属于后续算法阶段；防止把旧评价逻辑混进物理层 |
| `ALNSEnv.py::_guard_actual_window` | 用真实封锁状态阻止发车 | `Env/Env.py::_active_blocked`、`_process_departure` | 环境内部使用真实封锁状态；Snapshot只暴露当前观测状态 |
| `ALNSEnv.py::step` | 执行一个决策窗口 | `Env/Env.py::step` | 固定推进300秒，窗口内事件驱动 |
| `ALNSEnv.py::_advance`、`_simulate` | 推进列车/乘客事件 | `Env/Env.py::_advance_until`、事件处理函数 | 重写事件优先级、站台容量和逐事件守恒断言 |
| `ALNSEnv.py::_metrics` | 计算成本分项与守恒指标 | `Env/Env.py::metrics`、`_integrate_waiting` | 保留物理观测指标；移除ALNS目标分数与旧五项尺度依赖 |
| `ALNS.py`全部 | ALNS/LNS搜索、算子自适应 | `Legacy/Env/ALNS.py` | 原样归档；本次不适配新接口，不可直接接入V1 |
| `calibration.py` | 生成目标函数尺度 | `Legacy/Env/calibration.py` | 暂不运行；新物理层未冻结目标函数与权重 |
| `ResultRecorder.py` | 保存算法决策日志 | `Legacy/Env/ResultRecorder.py` | 原样归档；V1先返回StepResult，后续确定数据格式再适配 |
| `test_alns.py` | 旧ALNS/旧环境测试 | `Legacy/Env/test_alns.py` | 原样归档；新测试位于`tests/` |
| `run_alns.py` | ALNS命令行入口 | `Legacy/run_alns.py` | 原样归档；本次入口为`examples/run_demo.py` |

## 未迁移功能清单

1. ALNS/LNS搜索、破坏/修复算子和算子权重自适应。
2. 候选方案综合评分、五项metric_scales与多组目标权重。
3. 规则基线、LNS、ALNS对比和原ResultRecorder决策JSON格式。
4. 原版折返新增反向列车的时刻表插入/后续车序修复逻辑。

以上均属于算法或旧仿真策略层，不应在物理环境定型时暗中保留为环境自动决策。后续ALNS适配必须基于新`Snapshot`、`ActionPlan`和`StepResult`接口单独开展。
